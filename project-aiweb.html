AI_Web — 應用程式網路分流工具

一支 Go 桌面工具，讓「指定程式 / 指定網址」走「指定網卡」，把辦公網路與外部網路分流——不裝驅動、不 hook、不改系統 proxy，一般權限執行、對 EDR 友善。

Gowalk GUIgopsutilWindows sys API

背景與問題

有些程式要走辦公網路、有些要走外部網路——但在受資安控管的環境裡，不能裝驅動、不能注入程式、不能動系統全域 proxy。還必須一般使用者權限執行，且不能觸發 EDR（SentinelOne）。

解決方案

一支輕量 Go 程式，跑自寫的「綁來源 IP」代理，並針對瀏覽器設定「依網域」的路由——讓指定程式或網站的流量強制走指定網卡。由早期 Python 版重寫為 Go，並維持相同的設計約束。

技術亮點

  • 綁來源 IP 的代理 + IP_UNICAST_IF自寫 SOCKS5 / HTTP 代理設定封包來源 IP，並用 IP_UNICAST_IF socket 選項強制走指定介面——因為 Windows 預設 weak host send，光 bind 不一定真的走那張網卡。
  • 依網域的永久路由把網域解析成 IP，用永久路由釘到指定閘道；只有這一步觸發 UAC 提權，程式本身仍以一般權限執行。
  • Chromium 系瀏覽器處理設定正確的 --proxy-server 旗標與獨立的 user-data dir，讓 proxy 真的生效，而不是被併進已開的瀏覽器主進程。
  • 連線監控與自我修復列出哪些程式正在連線、網卡 IP 變動時自動刷新，並依保留期自動清理日誌。

成果

一個能在受控、有 EDR 的環境裡運作的安全輕量分流工具——不裝驅動、不注入、一般權限。
