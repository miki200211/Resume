個人作品

下班後自己做的 side projects——這是與工作分開、屬於我自己的空間。（下面是預留位置，填入你的真實作品即可。）

🤖 Android 行動開發

📊 量化監控 Kotlin

Winter Watch — 市場狀態監控器

為趨勢交易者設計的市場狀態監控器。透過 Binance 與 CoinGecko API，在 4h UTC 收盤時更新並比對 10 個量化指標（如 SMA200、Mayer Multiple、RSI 等）以辨識加密貨幣熊市的結束時機。基於 Kotlin、Jetpack Compose 與 Room。

Android (Kotlin / Compose / Room SQLite)
🔊 穿戴裝置 Kotlin

MemeWatch — 迷因語音板

專為 Android 手機與 Wear OS 智慧手錶設計的迷因語音播放器。支援自訂上傳與預設音效，可在手錶上快速播放好玩的音訊剪輯。使用 Jetpack Compose for Wear OS 與 Room 資料庫。

Android & Wear OS (Kotlin / Compose / sqlite)
📖 互動與 AI Kotlin

Book of Fate — 互動命運之書

具備重力感應的互動式命運占卜書。使用者只需搖晃手機即可翻開書頁，並向基於 Gemini API 的後端服務發送詢問以獲得指引。使用 Kotlin 與 Jetpack Compose 打造。

Android (Kotlin / Compose / Gemini API)
⚡ 網路工具 Kotlin

網路優化大師

網路狀態監控與最佳化工具。可自動測試多個 DNS 延遲並一鍵設定最佳 DNS，監控 4G/5G/Wi-Fi 延遲狀態，並支援 local DNS VPN 安全連線保護。基於 Kotlin 與 Android SDK。

Android (Kotlin / Android VPN / DNS APIs)

🛠️ 自動化與個人工具

📈 量化交易 Go

crypto-dashboard — 量化交易儀表板

將 4,000 多行 Python 量化交易系統完整移植至 Go 的桌面應用程式。以 Wails (Go + HTML/JS) 替換 PyQt 介面，使用 Goroutines 處理並行、Parquet 檔案做分區資料快取、對接 Binance API。

Desktop (Go / Wails / Parquet / Binance API)
🛡️ 系統工具 Go

VPN 快速連線工具

對接 VPNGate API 的 SoftEther VPN Client 連線工具。在背景執行 Go 伺服器並提供瀏覽器網頁介面，可自動偵測與建立虛擬網卡、獲取伺服器清單、依 Ping/速度計算品質評分並一鍵連線。

Desktop (Go / SoftEther vpncmd / Web GUI)
🔍 金融分析 Python

美股趨勢模板篩選器

依據 Mark Minervini 的 Trend Template 規則篩選美股的 Tkinter 介面工具。結合 yfinance 自動下載 OHLCV 資料，計算 SMA200、SMA150、52週高低點等趨勢指標，精準找出強勢動能股。

Desktop (Python / pandas / yfinance / Tkinter)
📄 辦公自動化 Python

Excel 批次轉 PDF 工具

實用 Tkinter 桌面小工具。呼叫 Win32 COM 介面自動操作 Excel 核心，一鍵將指定資料夾中所有的 Excel 活頁簿批次轉換為乾淨的 PDF 文件，避免排版跑版。

Desktop (Python / Tkinter / Win32 COM)
