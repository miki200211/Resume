TrackClose — 售後維修案件追蹤系統

  • 無頭 OCR 優化（放大 2 倍 + 字元白名單）大幅提升驗證碼辨識率
  • 爬蟲與 GUI 分離：背景執行緒 + 即時日誌視窗

CarMax 自動化工作流程 — 一鍵自動建案

從下載、比對、補資料、LLM 文本處理、格式轉換到上傳 JIRA 的完整流程，一鍵跑完。

  • 「真·超自動 PRO」：同時開兩個子行程跑 CMX / M-Box 兩組帳號完整流程
  • 並行下載 CarMax + JIRA，子行程輸出即時串回 GUI 日誌
  • 打包成 .exe 後用「重啟自己 + 環境變數」的 worker 機制共用同一條程式路徑
  • 成果：單案 30 分 → 2 分；文本轉換 3 分 → 1 分

網路工具 Go

AI_Web — 應用程式網路分流工具

讓「指定程式 / 指定網址」走「指定網卡」，在辦公網路與外部網路間分流；不裝驅動、不注入、EDR 友善。

  • 自寫綁定來源 IP 的 SOCKS5 / HTTP 代理，強制流量走指定網卡
  • 依網域設定永久路由，把特定網址釘到指定閘道（UAC 提權）
  • Chromium 系瀏覽器 proxy 參數與獨立設定檔處理
  • 連線監控、網卡 IP 變動自動刷新、日誌保留期自動清理
  • 由 Python 版重寫為 Go，維持「一般權限、不 hook」的設計約束

資訊安全 Go

Horizon — CSE 憑證橋接安全工具

不是密碼保管箱，而是「憑證橋接器」：有權限者用 GUI 密文寫入雲端，其他自動化程式只透過 CLI 取用。

  • 雙因子雲端金鑰：需「讀取權 + 正確公司網域」兩者兼具才能解密
  • 雲端憑證 AES-256-GCM、金鑰衍生 PBKDF2-SHA256（高迭代）
  • 本地設定走 Windows DPAPI，綁定當前登入使用者
  • HMAC-SHA256 簽章的稽核日誌（防竄改、逾期自動清除）
  • 機器綁定、Windows AD 驗證、金鑰輪換含回滾保護
